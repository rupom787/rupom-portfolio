## 🎨 Overview
Creative developer and designer portfolio featuring modern, interactive 3D web experiences, smooth scroll animations powered by GSAP and Lenis, and responsive design.

- **Frontend:** React 18, Vite, TypeScript
- **3D & Physics:** Three.js, @react-three/fiber, @react-three/drei, @react-three/cannon
- **Motion & Smooth Scroll:** GSAP, Lenis Smooth Scroll
- **Styling:** Vanilla CSS & Modular Components
